# Eredivisie
Eredivisie machine learning model

**kabollenbappers:** Daan Sijmens, Tristan Voermans & Tristan Veldkamp

|   | Goal Together with 2 friends i will spend 2 hours a week predicting Eredivisie matches using a model I build.|
|---|---|
| S | Study historical match results, build a simple model, and predict the scores for every matchday before kick-off. |
| M | I want to be able to correctly predict the scores 70% of the time. To do this we will take data from the past 2 seasons to predict the results of the matches in the next 8 weaks. |
| A | 2 hours per week fits in my schedule, for example in the evening or in the weekend. The model stays simple: we start with the results of the last 5 matches. We work together, so we can help each other when we are stuck. The winter break makes the season shorter, so we count at least 5 matchdays and not a fixed number.|
| R | Real data science work is teamwork, so dividing tasks, sharing code, and combining results builds skills that solo coursework doesn’t. Sports prediction is also a classic data science problem. |
| T | Week 1 collect last and this season’s data, make the 80/20 split, and build a baseline model together; weeks 2-3 improve the model and start predicting before kick-off; week 4 halfway check; weeks 5-7 add each matchday’s results, retrain, and predict the next one; week 8 final check on all matchdays and review what worked and what didn’t.  |
| E | Evaluate at the end of week 4 whether our model beats the home-team rule and whether the roles and the weekly check-in work for all three of us. |
| R | Revise the model if it loses to the home-team rule, for example by adding recent form or goal difference, and change the roles or meeting times if one of us is doing too much or too little.  |
